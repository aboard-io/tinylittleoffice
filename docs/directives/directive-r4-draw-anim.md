# R4-C: the Drawing Tool and the Animator

Read first: directive-r4-common.md, docs/editing.md (§5, §8), src/apps/draw/{model,editor,view}.ts and tests, src/apps/anim/{model,editor,view}.ts and tests, src/kit/text.ts (shape=line, no-bubble, the bubble), src/kit/context.ts, e2e/draw.spec.ts, e2e/anim.spec.ts.

Paul: "Drawing: I need to be able to rotate objects. Copy and paste makes two copies. Click and drag should let me select all the elements in an area. Move: I can't change the duration. I should be able to set looping rules and frames per second. Depth and size are the same. I can't rotate around the Y axis. Text should be rich text inside of objects, true for Draw too, boldable, underline, etc."

Drawing Tool:
1. **Rotate**: a `rot` (degrees, integer, 0 left out) per shape, a new optional column `Rot` in the table (read leniently, written only when set; byte-stable), drawn by `shapeSvg` as a `transform="rotate(a cx cy)"` around the shape's centre (lines and joins excluded, text included), the selection and handles drawn rotated too; set by a rotate handle (a small circle above the shape's top centre, dragged around the centre, 15° steps with Shift) and by the context bar (Rotate left/right 15°, as tools) and by keys `Mod+Alt+Left/Right`? No: keep keys to `[` and `]` on the canvas (15°) and say so in docs/editing.md §8. Motion inherits it (its Draw mode is Draw's editor; `spin` animates the same `rot`).
2. **Copy and paste makes two copies**: find why (the native clipboard event and the fallback both firing, or paste handled on the wrap and on document) and fix with a test that proves exactly one shape is added per paste.
3. **Marquee**: with Select in hand, a drag that starts on empty canvas draws a dashed box and, on release, chooses every shape whose box lies inside it (joins come along when both ends do); Shift adds to the choice. The context bar shows for the group; move, nudge, delete, duplicate, copy, colour and style act on all. A tap on empty canvas still deselects.
4. **Rich labels**: a shape's words become rich text: the Label column holds inline Markdown as the kernel writes runs (`writeInline`/`parseInline` from src/doc), the overlay becomes a `<to-text shape=line>` (its bubble on: bold, italic, underline, strike, highlight, link off; no lists, no footnotes: pass what the kit allows or hide the items), the SVG draws runs with `font-weight`/`font-style`/`text-decoration` tspans (view.ts), Motion's stage too. " | " line breaks stay. Update docs/editing.md §8 (the label is rich now) and the model's header comment. Byte-stable: a label with marks writes back the same.

Animator:
5. **Duration**: it must be editable (find why it is not: the Length menu, the head field, the frames count); make it a number field (frames) and a seconds readout, plus **fps** (a head field `fps`, default as now) and **loop** rules: a head field `loop: forever | once | n | bounce` (bounce plays forward then back), honoured by playback, the GIF export (loop count, the NETSCAPE extension) and the animated SVG.
6. **Depth vs size**: today they look the same. Make **size** the scale and **depth** the stacking order over time (which shape is in front; a far shape may also draw slightly dimmer, never smaller): the key table keeps both; the stage sorts by depth at the moment. Document the difference in the bar's tooltips.
7. **Turn** (rotation around the Y axis): a new keyed value `turn` (degrees) drawn as a horizontal scale `cos(turn)` with a flip past 90° (the shape mirrored), like a card turning; `spin` stays the rotation in the plane. Name it "Turn" in the bar.
8. Rich labels on the stage (item 4) and the GIF rasteriser (the kit's raster/gif path must draw the tspans).

Tests: node tests for rot in the table (round trip), marquee hit-testing, rich label round trip, loop/fps head fields, bounce frame order, depth sorting, turn's scale; DOM tests for the rotate handle, `[`/`]`, one paste one shape, a marquee drag choosing two of three shapes and the bar acting on both, bold in a label via the bubble and the SVG's tspan, the duration field, loop menu, turn slider; e2e lines in draw.spec and anim.spec at phone width (rotate handle reachable, marquee by finger with Select in hand).
