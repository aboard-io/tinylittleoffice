## What the skeleton is
A runnable, tested, deployable shell with no apps yet (one placeholder app "Text" that shows a title field and a bar, so the shell can be seen), on the new architecture:

1. **Toolchain**: Vite + TypeScript strict + Lit (pinned exact versions; the newest stable of each). No Shoelace, no UI library. Vitest in **browser mode** with the Playwright provider (chromium) for every test that touches the DOM, node for pure modules; Playwright for a small e2e smoke. Scripts: `dev` (host 0.0.0.0, port 4178, strictPort, allowed host pefdev.exe.xyz via `__VITE_ADDITIONAL_SERVER_ALLOWED_HOSTS` or server.allowedHosts), `build`, `typecheck`, `test` (unit + browser), `test:e2e`, `lint` (tsc is the lint; no eslint unless trivial). `npm` with package-lock.json. `.gitignore` for node_modules, dist, .env, test results. README.md: a short product paragraph, the layout, the commands, a pointer to docs/rebuild.md and docs/kernel.md (copy docs/rebuild.md into the new tree's docs/ verbatim; kernel.md is coming from another agent — leave a one-line placeholder).
2. **Layout**: `src/kit/` (shell, bar, insert, menu, toast, dialog, routing, store, privacy, offline, share, exports scaffolding), `src/doc/` (EMPTY except a README.md saying the kernel lands here per docs/kernel.md — do not write kernel types), `src/apps/<id>/{def.ts,editor.ts,style.css,templates.ts,tests/}`, `src/i18n/en.ts`, `src/styles/{tokens.css,kit.css,responsive.css,a11y.css}` or one `src/styles.css` with explicit `@layer tokens, kit, apps, responsive, a11y;` at the top and each app's style.css wrapped in `@layer apps { … }` — layers are the mechanism; use them.
3. **i18n from the first string**: `src/kit/i18n.ts` exports `t(text, vars?)`: English text is the key; `{name}` placeholders; plural via `Intl.PluralRules` with a form syntax `{n|one slide|# slides}` (document it); language from `navigator.languages` matched against the languages present (`import.meta.glob('../i18n/*.ts')`), override stored in localStorage and offered in the drawer labelled by `Intl.DisplayNames`; sets `<html lang dir>` (Intl.Locale textInfo where available, short RTL list otherwise). `src/i18n/en.ts`: a hand-edited TypeScript module (`export default {...} satisfies Strings`) with a header comment on how to translate, sections by area, one line per string, comments only where ambiguous. `scripts/i18n-extract.ts` + `npm run i18n:check`: scans `t('…')`, appends missing keys at the END under `// New — sort me into a section`, never reorders, reports unused and placeholder mismatches; a unit test fails on a missing key. English only ships.
4. **Shell** (`src/kit/shell.ts` and friends, Lit, native elements): hash routing `#/v1/<app>/<payload>` (v1: new format; the payload codec ported from old src/lib/codec.ts — read it, keep the dictionary deflate idea, port tests); home/launcher of app tiles (from a registry of AppDefs, lazy `import()` per app — a chunk per app from day one); header with the title as a visible field and the hamburger (native `<dialog>` as a side drawer or a `popover`): Find an app, Privacy (port the Private/Saved idea: keeping on device or not), Keep the app on this device (port src/sw.ts + the file list + offline.ts: hand-written service worker, Cache API, navigator.storage.estimate/persist, status line), Language, Theme (light/dark/auto via `prefers-color-scheme` + a data-theme attr; tokens for both with the dark-mode contrast the old a11y pass settled: see test/contrast.test.ts in the old tree and port that test), About. The **one bar** component `<to-bar>`: a single row that scrolls sideways with an edge fade (data attributes set by a scroll/resize observer), `tool()`/`btn()` helpers producing accessible buttons (aria-pressed, labels, 44px touch targets), an `<to-insert>` menu (Popover API) and a Download menu, a `<to-toast>` live region, `<to-menu>` (popover) and `<to-dialog>` (native dialog) wrappers. Share: copy link, QR (port src/lib/qr.ts + tests), short link (port src/lib/short.ts; the tinier client; `limits.ts` room meter). Everything phone-first: design at 390px in WebKit, inputs ≥16px, no page scroll on focus, popovers above the keyboard (visualViewport).
5. **AppDef** (`src/kit/app.ts`): the contract every app will fulfil, designed for the kernel: `{ id, name, group, icon, blurb, blank(): Doc-text, templates, editor: () => import(...), view(doc): Page[] (SVG/HTML pages for print/PDF/PNG), exports }` — write the type now with the kernel's Doc as an opaque `string` (TLO text) until src/doc lands; keep it minimal; the placeholder Text app implements it. Exports in the kit as the one mechanism: Print/Save as PDF via a hidden srcdoc frame and `@page` (port the idea of printHtml/printDoc from old src/kit/core.ts and browser.ts), PNG via canvas, HTML, Markdown/TLO text, `showSaveFilePicker` with `<a download>` fallback, `navigator.share` on phones.
6. **Security**: port public/_headers (CSP with hashed page scripts mechanism: read how `pageScript` hashes land in `_headers` at build in the old vite.config.ts and reproduce it), Referrer-Policy no-referrer, no inline script anywhere.
7. **PWA**: manifest, icons (copy public icons from the old tree), apple metas, theme.js (theme before first paint, hashed).
8. **Tests**: `test/` unit (node) for codec, qr, limits, i18n, contrast; `src/**/tests/*.test.ts` or `test/browser/` in Vitest browser mode for the shell: routing, drawer, bar overflow fade, insert popover keyboard (Esc returns focus), toast live region, theme switch, i18n switch with an in-memory `es` dictionary; one Playwright e2e smoke (home loads, open the placeholder app, no console errors, axe passes via @axe-core/playwright) and a phone-sized screenshot of home and the app at 390×844 WebKit saved to the scratchpad for the report.
9. **Deploy readiness**: `wrangler.jsonc` and the site Worker ported as-is from the old tree if the old one is a static-assets Worker (check `scripts/deploy.mjs` and the root wrangler config), so `npm run build` output is deployable later; do NOT deploy.

House rules: native web APIs first, ponytail minimalism, house voice (plain, short) in every string, every string through `t()`. One mechanism per idea. Pacing: this is a 2-core box shared with a design agent; one test command at a time; commit before long runs. Playwright browsers: `npx playwright install chromium webkit` once if missing.

Report: the tree (`tree -L 3 -I node_modules`), the AppDef type, what was ported from where (file → file), bundle sizes, exact test results, the screenshot paths, and what you left for the kernel/editor phases.
