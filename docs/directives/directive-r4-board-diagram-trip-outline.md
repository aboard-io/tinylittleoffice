# R4-D: the Kanban Board, the Diagram Maker, the Trip Planner, the Outliner's exports

Read first: directive-r4-common.md, src/apps/board/*, src/apps/diagram/*, src/apps/trip/*, src/apps/outline/{model,def,view}.ts, docs/editing.md.

Paul: "Kanban board: give each status color. Let me switch between vertical and horizontal orientation. Diagram maker: create the object focused on the label, like in other drawing tools; same is true for Org Chart, etc. Network: give me an icon in the menu that lets me join; don't make me tap. Maps: zoom in on my location from browser when I open. Outliner: when exported, footnotes should appear directly under their nodes as sub-nodes."

1. **Kanban colours**: every stage has a colour: the written `color` attr if any, else one from a fixed palette by position (the kit's named colours: distinct in light and dark, contrast-tested), shown as the stage's heading tint and a thin top edge on its cards; the stage menu's Colour stays to override. Templates unchanged (they read as before).
2. **Orientation**: a head field `look: columns | rows` (default columns): rows draws stages as horizontal bands one under another with cards flowing left to right (wrapping), which on a phone reads top to bottom; a bar menu or toggle switches; drag, Move to, Alt+arrows and the context bar work in both (the "across stages" direction becomes up/down in rows mode, keys unchanged). Byte-stable; a template may set it.
3. **Diagram: a new thing starts with its label in hand**: on every kind, a thing made by a tap, Insert ▾, Enter or the Add items opens with its words focused and the placeholder selected so typing replaces it (check each kind; fix the ones that do not). 
4. **Network Join as a button**: with a thing open or chosen, the context row/bar gets a **Join** tool (the join-two icon) that arms joining; the next tap on another thing makes the connection and disarms; Escape disarms. The old tap-tap path stays as a second way. The same tool on org, family and mind kinds where joins exist.
5. **Trip: open on my location**: when a trip with no stops opens and the map is shown, ask the browser for the position (`navigator.geolocation.getCurrentPosition`, once, with a 5 s timeout, no watching) and centre the map there at a city zoom; refused or unavailable, the map stays where it is. Say in the About/privacy line that the location is asked for only to centre the map and is never written anywhere. A trip with stops still fits to its stops. Test with a faked `navigator.geolocation`.
6. **Outliner exports with footnotes as sub-nodes**: in the OPML, the text and the Markdown exports, each footnote of an item becomes a child item right under it (first among its children), its words the note's, prefixed with its number ("1. …" for text/md as the outline numbers it, or the note's mark); the page view may stay as it is. Node tests for all three.

Tests: DOM and node tests for every item (colour by position and override, rows mode layout and moves, label focus per kind, Join tool, geolocation centring and refusal, exports); a phone e2e line for the Board in rows mode and for the Join button. PW_PORT=4403.
