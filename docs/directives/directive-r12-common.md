# Round twelve — the common contract

Everything in directive-r4-common.md holds (read it first), with directive-r9-common.md's, directive-r10-common.md's and directive-r11-common.md's rules (one style: `npm run format` before each commit; delete outright; a finding is a failing test; growth is fine where it buys simplicity). Round eleven's tree is the base.

This round is for the agents that write documents, Paul's answer of 2026-10-11 to what would have made a deck easier for one: *"Doc that. Also never look at it. Why are you looking? You've got a parsing API and can measure and set parameters."*

The rule of the round: **an agent never opens a browser to check a document.** Whatever a screenshot would show, the layout already knows, and the API says it in words and numbers. Where today it cannot, this round makes it say so. The skill (`skill/tinyoffice/SKILL.md`, generated by `npm run skill` from `scripts/make-skill.ts` and what it reads) is the agents' one document: a rule that lives nowhere else is lost.

Tests: node for the lint and the API, one browser test only where layout measurement needs a real font; `npx vitest run` whole at the end; `npm run build`; nothing of this ships in `dist` but what the API already is.
