# RS-3: the agent and sharing surface

Rows: docs/gap-analysis.md "Agents and sharing" (all missing and partial rows) and the Exports rows (.md for every app, the .pdf file, the Outline text PDF, Deck's show link). Old tree: skill/, scripts/make-skill.ts, src/api.ts, public/tinyoffice.js, packages/doc, src/lib/diff.ts, widgets/compare.ts, public/llms.txt, public/og/ and make-icons.mjs, kit/pdf.ts, kit/textpdf.ts, the share targets in the old share code. New tree: src/kit/{exports,share,route,codec,page,draw,raster,zip}.ts, src/doc (the kernel is the API now), the Share dialog, public/_headers (the CSP and framing).

Build (each on its own merits, as the new tree would):
1. **The agent skill**: `skill/tinyoffice/SKILL.md` generated by `scripts/make-skill.ts` from the registry and docs (the apps, their nouns, the TLO format per app with one example each from the templates, the link forms, the short-link API, the signing envelope), with a test that the generated skill matches the committed one; `public/llms.txt` likewise generated.
2. **Plain-parameter links** `#title=&doc=&app=&by=` and `#md=` (a way for an agent or a person to make a document from a URL without the codec), read by route.ts and turned into the canonical `#/v1/…` on arrival (replaceState); documented in the skill.
3. **`/api.js` and the `tinyoffice` command line** (`packages/doc`): a tiny ESM module exposing `encode/decode/parse/write/link` over the kernel, built by Vite as its own entry, and the CLI that makes links from files and files from links; tests.
4. **`.tlo` file open** (drag a file on the page, or a File ▾ Open in the hamburger) and **Download .tlo** for every app; **Markdown export** for every app (write() of the document); **a direct .pdf file** (`kit/pdf.ts`: the drawn pages as a PDF with embedded SVG-as-vector or raster per page, as the old one did; say which) beside Print; the Outline's text PDF.
5. **Compare**: `#/compare` route and a Compare… item in the hamburger: two links (or this document and a pasted link) diffed block by block (port lib/diff.ts), shown side by side with changes marked, phone: stacked.
6. **Share targets**: in the Share dialog, Bluesky, Mastodon (asks the instance once, kept under Saved), X, LinkedIn and Email, each opening the service's share URL with the title and link through the link guard; **Copy embed code** and the `.embed` view (a minimal page of the document's pages; `_headers` allows framing for that route only).
7. **Deck's show link** (`?show` opens presenting) and **copy-a-download-link** items (a link that downloads the .pdf/.docx/… directly) in the Download menu.
8. **Per-app share cards**: `scripts/make-cards.ts` draws `public/og/<app>.png` from each app's first template page through the kit's raster, wired into the per-app pages' meta; the home card is the Office mark.

Tests: node for the skill generation, plain links, the API module, diff; DOM for open/download .tlo, compare view, share targets (window.open stubbed through the guard), embed code; the e2e smoke checks `/llms.txt` and `/api.js` are served. PW_PORT=4421.
