# Languages, part two: one language file

You are translating Tiny Little Office's strings into one language, named in your prompt. Read first: src/i18n/en.ts in full (its header is the format: the key stays exactly as it is on the left; the value is your language on the right; keep every {placeholder} once; a plural `{n|one slide|# slides}` becomes the forms your language has, in the order zero, one, two, few, many, other — only the ones the language has, as `new Intl.PluralRules(code).resolvedOptions().pluralCategories` lists them — with `#` for the number; keep the section comments, translate nothing in them), src/kit/i18n.ts's header, docs/editing.md's first page for the product's voice, and README.md's first paragraph for what the product is.

The voice: plain words a person would say, never jargon; sentences, not labels, where the English is a sentence; the same register as the English (friendly, direct, never cute). Keep these as they are: "Tiny Little Office" (never translated), "TLO", app ids, keyboard key names as the OS shows them (Mod, Shift, Enter, Escape, Tab, Arrows). Translate the apps' names the way a native office suite would ("Word Processor", "Spreadsheet", "Presentation Builder", "Outliner", "Kanban Board", "Website Builder", "Drawing Tool", "Animator", "Diagram Maker", "Calendar", "To-do list", "Trip planner", "Calculator"), and keep one translation per term throughout: make a glossary of the forty most frequent product terms first (document, link, short link, display link, kept, saved on this device, password, signed, template, card, slide, sheet, cell, page, bar, Insert, Share, Undo, Redo, the app names) and use it everywhere. Length: a string on the bar or in a menu (the sections "the bar", "the drawer", every app's bar strings) at most a third longer than the English; a button's label the same length or shorter; shorten by choosing a shorter word, never by dropping meaning. Typography of the language (its quotation marks, its spacing before punctuation where it has it, its number and date words).

Work in your worktree only (your prompt says where); write src/i18n/<code>.ts; run `npm run i18n:check` and `npm run i18n:gaps -- <code>` until both are clean (they verify keys, placeholders and plural-form counts); run `npx vitest run test/i18n.test.ts` (one test command at a time; nothing in the background). Then read your file once more top to bottom as a native reader would and fix what reads like a translation.
