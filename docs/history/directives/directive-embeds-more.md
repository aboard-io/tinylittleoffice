# More embeds, native first

Paul asked: "Did you add embed capabilities for well known embeds? YouTube, internet archive, social media, what else?" Today src/lib/embeds.ts `embedOf(url)` knows YouTube (nocookie), Vimeo (dnt), Bluesky (handle resolved on tap), X (dnt) and remote images. Everything is a click-to-load card: no third-party request before the tap, a sandboxed iframe with referrerpolicy=no-referrer after it, and public/_headers lists exactly the frame-src hosts. Keep those three properties for everything you add. Native web APIs first (Paul: "use the browser wisely").

Add, each with a pure unit test of the URL → Embed mapping and the CSP line it needs:
1. **Native media, no provider**: a URL ending in .mp3/.ogg/.wav/.m4a/.flac → `<audio controls preload="none">`; .mp4/.webm/.mov/.m4v → `<video controls preload="none" playsinline>`; .pdf → the browser's own viewer in a sandboxed `<iframe>` (or `<object>`); still behind the card (the tap sets the src). `img-src`/`media-src` in the CSP: `media-src https:` is needed; add it. Also .svg as image (treat like images, but note SVG can carry script: load it as `<img>` only, never inline).
2. **Internet Archive**: `archive.org/details/<id>` → `https://archive.org/embed/<id>` (audio, video, books; the embed endpoint works for all); Wayback `web.archive.org/web/<ts>/<url>` → framed as is (it is the archive's own page) with provider "Wayback Machine".
3. **Mastodon**: a post URL `https://<instance>/@<user>/<id>` (also `/users/<user>/statuses/<id>`) → `<same>/embed`. The instance is any host, so the CSP cannot list it: decide and document. Options: (a) frame-src `https:` for post embeds (broad, but only after a tap into a sandboxed frame), or (b) a card that opens the post in a new tab instead of framing. Prefer (a) if the sandbox and the tap make it acceptable; say why. Same for **PeerTube** (`/w/<id>` or `/videos/watch/<id>` → `/videos/embed/<id>`; recognise by path shape, provider "PeerTube"), and for any **TinyLittleOffice** link (already handled as a Document; make sure a pasted tinylittleoffice.com or tinier link is left alone by embedOf).
4. **Music**: Spotify `open.spotify.com/(track|album|playlist|episode|show)/<id>` → `open.spotify.com/embed/<kind>/<id>`; SoundCloud → `https://w.soundcloud.com/player/?url=<encoded>&visual=false`; Bandcamp (needs the album id, which is not in the URL: give a link card). Podcast RSS: no.
5. **Places and code**: OpenStreetMap `openstreetmap.org/#map=z/lat/lon` or `?mlat=&mlon=` → `https://www.openstreetmap.org/export/embed.html?bbox=…&marker=lat,lon`; CodePen `codepen.io/<user>/pen/<id>` → `codepen.io/<user>/embed/<id>?default-tab=result`; Reddit post → `https://embed.reddit.com/r/<sub>/comments/<id>/…?embed=true&theme=dark|light`; Wikipedia article → a card that on tap fetches `https://<lang>.wikipedia.org/api/rest_v1/page/summary/<title>` and shows the extract and thumbnail (connect-src for `*.wikipedia.org`), with "Read on Wikipedia".
6. **No script-free embed**: Instagram, TikTok, Threads, Facebook, LinkedIn, GitHub gists → a link card: the provider's name, the path's readable part, and "Open on <provider>". Any other URL that is alone on a line stays a plain link as today (do not card every link).
7. **Where embeds appear**: they already work in Write, Outline items and a Deck slide (full-slide). Check Website sections and Quick Links (a pasted video URL in a section should become the same card; the generated static page must carry the click-to-load behaviour with the page's CSP-hashed script, or render a plain link with a thumbnail-free card that links out — pick the simpler that works offline) and the Board card text. Insert ▾ "From the web" should list what is supported in a one-line hint.
8. Docs: README privacy paragraph and the embeds list; skill/tinyoffice/SKILL.tpl.md gets the supported providers so agents know what a bare URL line does; `npm run skill`.

Keep the module pure and small; `embedOf` stays a single function of the URL. Tests: one table-driven unit test over all providers (URL → provider/src/kind), negative cases (a plain article URL is not an embed; a TLO link is not), and a DOM test for audio/video/pdf cards (no network before tap, correct element after).
