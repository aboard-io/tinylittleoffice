# The documents

Every page in this folder, one line each. Start with the repository's README for what Tiny Little Office is;
start here for how it is made and why.

## What it is, and what it promises

- [transparency.md](transparency.md): the pre-launch list for opening the code, and the words used to say what this is.
- [threat-model.md](threat-model.md): what the passwords and short links protect against, and what they do not.
- [network.md](network.md): what leaves your browser: every request the site can make, when, what it carries, what stops it.
- [dependencies.md](dependencies.md): every package, its version and licence, the native API it beat, and the bytes it adds (generated).
- [self-host.md](self-host.md): running your own copy on your own Cloudflare account, in about thirty minutes.

## How it is built

- [rebuild.md](rebuild.md): the plan of the rebuild, its phases, and the rules kept while building.
- [kernel.md](kernel.md): the document kernel, the one editor and sheets as the data model: the design and its decisions.
- [tlo.md](tlo.md): the document format, as a person or a language model learns it.
- [editing.md](editing.md): the one editing standard every app keeps, by keyboard, pointer and finger.
- [exports.md](exports.md): the files each app's documents become, and the apps they open in (generated).
- [translation.md](translation.md): the plan for ten languages, right to left included.

## Records and checklists

- [gap-analysis.md](gap-analysis.md): what the old tree did, feature by feature, and where the rebuilt tree stands.
- [github-setup.md](github-setup.md): the repository's settings, applied by hand in GitHub before it goes public.
