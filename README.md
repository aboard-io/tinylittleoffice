# Tiny Little Office

## General Notes
The document is the link.
- A letter, a spreadsheet, a presentation or a calendar is held in the address of its page
- Copy the link and you have copied the document
- Whoever has the link has the document.
- There is no account.

Each link is the whole document: open it, change it, and the link in the address bar is your copy. Twenty-five more are in [samples/](samples/), as files.

Private by default.
- By default nothing is kept, on your device or anywhere else.
- Your browser might save the link in history, of course. Use incognito mode if you want
- If you decide to save, it keeps your documents on your own device, never on a server.
- If you save a short link, it's encrypted with a key the server never sees.
- If you decide to use the social sharing functionality it will make a preview card and save that on a server.

Utterly fine with AI agents.

- An agent has three ways in:
1. [/llms.txt](public/llms.txt) for a fetch;
2. `npx tinylittleoffice` with a runtime ([packages/doc](packages/doc/README.md));
3. And, for Claude Code, the [skill](skill/tinyoffice/SKILL.md) (a short SKILL.md and a reference an app), installed with `npx tinylittleoffice skill --into ~/.claude/skills`.

## Developers

Node 24 or later.

```sh
npm install
npm run dev      # the site at http://localhost:4178
npm test         # every test, under Node and in Chromium
npm run build    # the site as it ships
```

## Deploy with Docker
```sh
docker build -t tinylittleoffice docker
docker run -d --restart=unless-stopped -p 7110:80 -e VITE_ALLOWED_HOSTS=<your_domain> --name tinylittleoffice tinylittleoffice
```

Then access from `127.0.0.1:7110`

**Notes:**
- `-e VITE_ALLOWED_HOSTS=<your_domain>` is not required if you're only accessing it from localhost.
- Allowed hosts is a comma-separated list of domains

How it is made, what it protects against and how to run your own copy are in [docs/](docs/README.md): the
[threat model](docs/threat-model.md), the [cryptography](docs/crypto/password.md), [self-hosting](docs/self-host.md).
When tinylittleoffice.com is down, the same tag runs on GitHub Pages at https://aboard-io.github.io/tinylittleoffice/
(the [mirror](docs/mirror.md)): put that before the `<app>/#…` of a link and it opens there.

A security problem should be reported privately, through the repository's Security tab, never as an issue.
